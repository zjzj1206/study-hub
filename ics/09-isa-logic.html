09 · Y86-64 指令集与逻辑设计

依据第 9 讲 2026-10-15 课件全部 64 页和第 9 讲小班研讨单。先规定机器“应该做什么”，再用逻辑门、组合电路和存储元件实现它；第 10 章进一步构造 SEQ。第 9、10 讲是第一次测验之后的新授内容。

ISA：软件与硬件共同遵守的约定#

  • ISA（指令集体系结构） 规定程序可见状态、指令语义与编码、寻址方式及停止/错误状态。它说明执行前后哪些状态如何变化。
  • 微体系结构规定用什么数据通路、控制逻辑和时钟组织实现 ISA。同一 ISA 可以有不同实现。
  • Y86-64 的程序状态：15 个 64 位通用寄存器、ZF/SF/OF、PC、程序状态 Stat 和按字节编址的内存。没有 %r15，也没有这里可供 unsigned 条件使用的 CF。
  • 内存与字：每个地址对应一个字节；64 位字占 8 字节，多字节常数、位移和数据按小端存储。指令的第一个字节本身由两个半字节组成，不把它们倒置。
  • PC：标识当前要执行的指令；顺序执行后更新到下一条。取指得到的 valP 是顺序后继地址，不保证最终 PC 就等于它。

  • 寄存器字节的高半字节为 rA，低半字节为 rB。有些指令不使用其中一侧，规定在该位置填 F。

指令格式、语义与长度#

以下 R[r] 表示寄存器值，M8[a] 表示从地址 a 开始的 8 字节字；Cnd 为用当前 CC 和 ifun 判断出的布尔条件。指令首字节是 icode:ifun，其中每部分各 4 位。

指令 字节布局（空格分字段） 长度 核心语义
halt 00 1 停止，状态变为 HLT
nop 10 1 不改数据，PC 顺序前进
rrmovq rA,rB 20 rArB 2 R[rB] ← R[rA]
cmovXX rA,rB 2f rArB 2 条件真才传送；条件假保留目的寄存器
irmovq V,rB 30 FrB V 10 R[rB] ← V，V 占 8 字节
rmmovq rA,D(rB) 40 rArB D 10 M8[R[rB]+D] ← R[rA]
mrmovq D(rB),rA 50 rArB D 10 R[rA] ← M8[R[rB]+D]
OPq rA,rB 6f rArB 2 R[rB] ← R[rB] OP R[rA]，并更新 CC
jXX Dest 7f Dest 9 条件真转到绝对地址 Dest，否则顺序前进
call Dest 80 Dest 9 压入顺序后继地址，再转到 Dest
ret 90 1 从栈读返回地址，再更新 PC
pushq rA A0 rAF 2 栈指针减 8，再存入源寄存器原值
popq rA B0 rAF 2 从旧栈顶取值，更新栈指针，并写目的寄存器
  • 编码长度由首字节所表示的指令类别确定。寄存器字节可选，8 字节常数字段可选，因此长度为 1、2、9 或 10 字节。
  • rrmovq 与条件传送共用 icode=2；不是另开一套 opcode。
  • 基础 Y86-64 不直接提供 cmpq、testq、leaq、立即数 addq、比例索引寻址、硬件乘除法。翻译 x86 程序时必须展开。
  • subq rA,rB 计算的是目的减源；load 的目的寄存器编码在 rA，不能按汇编文字顺序猜 rB。

OPq 与条件功能码#

OPq 的 ifun 指令 运算
0 addq rB + rA
1 subq rB - rA
2 andq 逐位与
3 xorq 逐位异或

令 L=SF⊕OFL=SF\mathbin{\oplus}OFL=SF⊕OF。条件传送和跳转共用下表的条件含义；无条件功能码对应 rrmovq 或 jmp。

ifun 后缀 条件 Cnd 有符号比较含义
0 无条件 真 总是执行
1 le L∨ZFL\lor ZFL∨ZF 小于等于
2 l LLL 小于
3 e ZFZFZF 等于
4 ne ¬ZF\neg ZF¬ZF 不等于
5 ge ¬L\neg L¬L 大于等于
6 g ¬L∧¬ZF\neg L\land\neg ZF¬L∧¬ZF 大于
  • “比较含义”以之前执行的减法为依据。例如先计算 x-y，再用 jl 判断 x<y。
  • 加减按 64 位截断。ZF 表示结果为零，SF 为结果最高位；加法同号输入得到异号结果、减法异号输入得到与被减数异号结果时，OF 为 1。
  • andq/xorq 按结果设置 ZF、SF，并清 OF。cmovXX/jXX 读取 CC，不更新 CC；地址加法、栈指针加减也不更新 CC。

栈、调用与程序状态#

  • 栈向低地址增长：若原 %rsp=s，push 后的新栈顶为 s-8；栈顶不是“最高地址”。第 18 页中与此相反的英文小句应按图与实际操作纠正。
  • push：保存原源值，计算新 %rsp=s-8，将原源值写到 M8[s-8]。pushq %rsp 存的是旧 s。
  • pop：从 M8[s] 取得 valM，再形成 s+8；popq %rsp 的目的写回优先，最终 %rsp=valM，不能简单断言总增加 8。
  • call：如果指令位于 p，则顺序后继地址为 p+9。把这个地址压栈，再转到编码中的 Dest。
  • ret：读取旧栈顶作为下一 PC，栈指针通常增加 8。它没有编码中的 Dest。
  • AOK=1 为正常执行；HLT=2 为 halt 停止；ADR=3 为指令或数据地址错误；INS=4 为非法指令。后三者使模拟器停止。Y86 的 halt 是教学模拟指令，不能等同于普通用户态可随意执行的 x86 hlt。

Y86 的绝对跳转与 x86 的相对跳转#

  • Y86 jXX/call 的 8 字节字段直接装目标地址，硬件可直接选择 valC。
  • x86-64 的常见直接近跳转和直接相对 call 编码的是相对下一条指令的位移；目标为“顺序后继 RIP + 符号扩展位移”。
  • x86 也存在通过寄存器或内存操作数的间接 jmp/call；不能把“PC 相对”概括成所有控制转移。常见 Jcc 没有对应的通用寄存器间接条件跳转形式。
  • Y86 的设计简化了变长偏移选择、目标形成和教学译码，代价是每个跳转都占 9 字节，也没有自动获得 PC 相对编码的紧凑性与位置无关便利。

从 C 翻译为 Y86：一个可运行的完整例子#

目标是遍历以零结尾的 long 数组，返回零之前的元素数；本例采用 LP64，long 为 8 字节。

long len(long *p) {
    long n = 0;
    while (*p != 0) { ++n; ++p; }
    return n;
}
  • x86 可用 addq $1,%rax、addq $8,%rdi 和 cmpq $0,(%rdi)。
  • Y86 先把常数装进寄存器，以寄存器加法替代立即数加法；用 load 加 andq %rdx,%rdx 替代内存比较。
  • 以下程序使用标签、.pos、.align、.quad；这些是汇编器指示，不是 CPU 执行的指令。
.pos 0
    irmovq stack,%rsp
    irmovq array,%rdi
    call len
    halt
.align 8
array:
    .quad 0x123
    .quad 0x456
    .quad 0x789
    .quad 0
len:
    irmovq $1,%r8
    irmovq $8,%r9
    xorq %rax,%rax
    mrmovq 0(%rdi),%rdx
    andq %rdx,%rdx
    je done
loop:
    addq %r8,%rax
    addq %r9,%rdi
    mrmovq 0(%rdi),%rdx
    andq %rdx,%rdx
    jne loop
done:
    ret
.pos 0x200
stack:
  • 程序从地址 0 开始，显式初始化栈指针；数据区、代码区和栈空间要避免重叠。
  • 用 CS:APP 的 yas len.ys 汇编为 len.yo，再用 yis len.yo 执行；汇编输出给出地址与字节，模拟结果给出状态与寄存器变化。
  • 下载：len.ys 源码、len.yo 汇编结果、官方 yis 实测输出。已在本机命令行执行 yas 与 yis，并验证空数组与单元素变式。
  • 本例正常结束应为 HLT，%rax=3，%rdi=array+24，%rsp=0x200。空数组测试应返回 0，不能先递增再检查。
  • 编译器未必按源代码外形生成相同汇编；第 25 页的例子说明手写指针形式仍可能被优化成比例索引形式。编译结果需按目标 ISA 重新改写。

CISC、RISC 与课件中的 MIPS 例子#

  • CISC 常有较多指令形式、复杂寻址、变长编码；代码密度和兼容性可有优势，但译码与实现更复杂。
  • 典型 RISC 采用较规则的编码、较多寄存器和 load/store 风格，算术主要在寄存器之间完成，便于规则的数据通路设计；同一任务可能需要更多指令。
  • 课件的 MIPS 有 32 个寄存器，$0 固定为零；其示例 add rd,rs,rt 为三操作数，lw/sw 使用基址加位移。这些是 MIPS 约定，不能移植为 Y86 规则。
  • 两类都能采用流水线、预测、乱序等技术；实际性能还依赖实现、编译器、缓存与工作负载，不能仅凭类别判断快慢。Y86 同时保留 x86 风格状态、变长指令和简化的操作数形式。

数字信号、逻辑门与组合电路#

  • 数字信号用电压范围代表 0/1，中间留出容限区；实际电压连续变化，并非只能取两个精确电压。
  • 组合电路是无环逻辑网络；输出在传播延迟后由当前输入决定，没有在某一时钟沿才统一计算的要求。
  • 传播延迟：输入变化到输出稳定需要时间。多级路径延迟会累积；时序图中先算理想布尔结果，再按门延迟移动变化时刻。
  • 逻辑与/或/非分别实现 a∧ba\land ba∧b、a∨ba\lor ba∨b、¬a\neg a¬a；布尔输入是单比特，勿混同 C 的任意整数非零判断或整字逐位运算。

  • 一位选择器：out=(s∧a)∨(¬s∧b)out=(s\land a)\lor(\neg s\land b)out=(s∧a)∨(¬s∧b)，s=1 选 a，s=0 选 b；共有 8 种输入，按 s 分两组即可逐一验算。
  • 字选择器：给每一位复制相同的选择规则，共用选择信号 s；它选择完整输入字，不进行算术运算。
  • ALU：按功能选择加、减、与、异或结果；逐位 AND 可由 64 个 AND 门并行形成，再通过选择器选择。加减还需进位结构，并由结果/输入计算标志。

HCL：声明逻辑关系，不是按行执行的 C#

  • bool 为布尔信号，int 为字信号；HCL 的 int 并不自行规定“C 语言 32 位 int”，具体字宽由硬件对象决定。
  • 布尔运算、比较、集合成员关系产生布尔值；字 case 表达式产生数据字。
  • A in {B,C,D} 表示 A 等于其中至少一个值；[ 条件:值; ... ] 按从上到下的第一条真条件选值，末尾 1: 提供默认值。
  • case 的优先级描述选择关系，不表示硬件必须像软件一样跨多个周期逐条试条件；网络仍可由组合逻辑实现。
bool eq = (a && b) || (!a && !b);
int Out = [ s : A; 1 : B; ];
bool hit = code in { OP1, OP2, OP3 };
int Out4 = [
    !s1 && !s0 : D0;
    !s1        : D1;
    !s0        : D2;
    1          : D3;
];
int Min3 = [
    A <= B && A <= C : A;
    B <= A && B <= C : B;
    1               : C;
];
  • 四选一对应 (s1,s0)=00/01/10/11 依次选 D0/D1/D2/D3。后面条件之所以省略一部分，是前面已排除了其他情况。

时序电路：寄存器、寄存器堆与状态机#

  • 硬件寄存器存一个字，在指定时钟沿采样输入，沿之间保持输出；程序寄存器 %rax 等是 ISA 名称，物理上由寄存器堆实现。
  • 寄存器堆有读地址 srcA/srcB、读输出 valA/valB，以及写地址、写值和写使能。课程模型异步读、在时钟上升沿写；选择读地址后不必等待下一拍才读出。
  • 写后读：时钟沿写入完成后，若读地址选中该寄存器，读端在组合延迟后反映新值；“写入”和“输出变化”不应画成提前发生。
  • RAM通过地址选取存储位置。本课程模型的数据读为组合路径的一部分，写入在时钟沿更新；这不代表所有实际内存器件都采用相同时序接口。
  • 状态机由状态寄存器和组合逻辑组成。用当前状态 QtQ_tQt​ 与输入 ItI_tIt​ 计算候选 Dt=f(Qt,It)D_t=f(Q_t,I_t)Dt​=f(Qt​,It​)，到边沿才有 Qt+1=DtQ_{t+1}=D_tQt+1​=Dt​。
  • 第 51 页累加器：Load=1 时 Qt+1=IntQ_{t+1}=In_tQt+1​=Int​，Load=0 时 Qt+1=Qt+IntQ_{t+1}=Q_t+In_tQt+1​=Qt​+Int​。课件时序输出依次为 x0,x0+x1,x0+x1+x2,x3,x3+x4,x3+x4+x5x_0,x_0+x_1,x_0+x_1+x_2,x_3,x_3+x_4,x_3+x_4+x_5x0​,x0​+x1​,x0​+x1​+x2​,x3​,x3​+x4​,x3​+x4​+x5​；第三次累计后重新加载 x3，不继续加到旧和。

附加材料：一位存储、锁存器与边沿触发#

  • 双稳态：反馈电路有两种稳定状态，分别保存 0 和 1；中间平衡点可能不稳定或出现亚稳状态，不能把模拟电压曲线理解成第三种可靠逻辑值。
  • 课件的 NOR 型 R-S 锁存器：R=S=0 保持；R=1、S=0 复位 Q=0；R=0、S=1 置位 Q=1；R=S=1 为禁用组合，不应用来表示正常数据。
  • D 锁存器通过互补信号限制 R/S 同时置位。图中 C=1 时透明，输出经过延迟跟随 D；C=0 时保持。它是电平敏感，不是整个高电平期间只采样一次。
  • 边沿触发存储仅在上升沿附近短暂采样，之后保持；需要满足采样窗口附近的建立与保持时间。该节解释寄存器如何“记住”，不要求把所有模拟晶体管细节当成 ISA 定义。

  • 手工编码一条 2 字节和一条 10 字节指令，并从字节反解 rA/rB 与常数。
  • 比较 cmovle 和 jle：读同一类条件，但前者选择目的写回，后者选择 PC。
  • 给出输入时序，分别画组合 OR 的延迟输出、D 锁存器的透明区间和边沿寄存器的保持区间。
